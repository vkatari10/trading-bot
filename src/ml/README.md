# ML 

## `data_processing/`
- Contains methods to fit DataFrames with user based configs

## `json/`
- Contains the `UserConfig` class to represent a config file

## `models/` 
- Contains dumped models ready to be used at live execution 

## `training/`
- Contains methods to train models on given DataFrames

## `pipeline.py`
- Script ran to run the entire ML pipeline given a config file
